IOB Configuration Main Menu

The IOB device requires information about the network, the locomotive prototype parameters, and the function definitions in the model. Existing values are displayed.

The values entered here will be stored aboard the loco and need not be entered again unless changes are required. Please note that certain changes will require the software to be rebooted.

The IOB application itself can be updated over the wireless connection. If a new version has been supplied, use the Update menu item.
